### Step 3: Allow Installation from Unknown Sources

Android blocks installations from outside the Play Store by default. To allow this:

1. Open your device **Settings**.
2. Tap **Security** or **Privacy** (the exact name varies by Android version).
3. Find the toggle for **"Unknown sources"** or **"Install unknown apps"**.
4. Turn it **ON** for your browser or file manager app.

If you're unsure, your device might show a pop-up asking for permission when you open the downloaded file – just tap "Allow" then.

### Step 4: Open and Install the App

1. Locate the downloaded `.apk` file – check your **Downloads** folder or notification shade.
2. Tap the file to open it.
3. Android will ask you to confirm – tap **"Install"**.
4. Wait for the installation to finish – this usually takes under a minute.

### Step 5: Launch and Set as Home

Once installed, you'll see the KONSORU icon in your app drawer. Tap it to open the app for the first time.

Android will ask if you want to use KONSORU as your **home app**. Select **"Always"** to make it your default launcher. If you ever want to go back to standard Android, go to Settings > Apps > Default apps and choose another launcher.

## 🎮 Using KONSORU Launcher

### First-Time Setup

When you open KONSORU for the first time, you'll see a welcome screen. Here's what to do:

- **Grant permissions** – KONSORU needs access to your storage to find games. Tap "Allow" when prompted.
- **Choose your consoles** – The launcher will scan your device for installed emulators and show you which ones it found.
- **Set up themes** – Each console section has its own visual theme. You can adjust these anytime in settings.

### Adding Games

To add games to your library:

1. Make sure your ROM files are on your device – either in internal storage or an SD card.
2. Open KONSORU and navigate to the console you want to add games to.
3. Tap the **"+"** or **"Add Games"** button.
4. Browse to the folder where your ROMs are stored and select them.
5. KONSORU will create shortcuts and apply the console's theme to each game.

### Navigating the Interface

- **Swipe left/right** – Switch between different console screens.
- **Tap a game** – Launch it in the appropriate emulator.
- **Long-press** – Access options like favorite, edit, or remove a game.
- **Pull down from top** – Open the settings menu.

## 🔧 Troubleshooting Common Issues

### App Won't Install

- Make sure you've allowed "Unknown sources" – see Step 3 above.
- Check that you have enough free space – the app needs about 50MB.
- Try restarting your device, then install again.

### Games Won't Launch

- Verify the emulator for that console is installed and updated.
- Make sure your ROM file is compatible with your emulator version.
- Some games need BIOS files – check your emulator's documentation.

### Launcher Looks Wrong or Acts Glitchy

- KONSORU is in public beta, so some rough edges are expected.
- Try clearing the app cache: Settings > Apps > KONSORU > Storage > Clear Cache.
- If problems persist, see the "Known Issues" section below.

### Can't Find Downloaded File

- Check your **Downloads** folder using a file manager app.
- Some browsers download to a "Download" subfolder in storage.
- Use a file manager to search for ".apk" files.
